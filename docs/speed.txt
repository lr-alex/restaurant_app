Saffron & Stone REST API Manual Walkthrough
===========================================

Run these commands in PowerShell.

Use two terminals:

1. Terminal 1 runs the application.
2. Terminal 2 runs the API commands.

Run the steps in order because later commands reuse variables from earlier
commands.


TERMINAL 1 - START THE APPLICATION
==================================

cd D:\study\hkmu\comp_3810_sever-side\proj\restaurant_app

npm run reset

npm start

Keep Terminal 1 running.


TERMINAL 2 - SET THE BASE URL
=============================

cd D:\study\hkmu\comp_3810_sever-side\proj\restaurant_app

$base = "http://localhost:8099"


STEP 1 - SESSION CREATE
=======================

$customer = New-Object Microsoft.PowerShell.Commands.WebRequestSession

$customerLogin = Invoke-RestMethod `
  -Method Post `
  -Uri "$base/api/session" `
  -WebSession $customer `
  -ContentType "application/json" `
  -Body (@{
    username = "customer1"
    password = "Customer@123"
  } | ConvertTo-Json -Compress)

$customerLogin | ConvertTo-Json -Depth 5

Expected:

username = customer1
role = customer
profile.name = Bob Johnson


STEP 2 - SESSION READ
=====================

$currentSession = Invoke-RestMethod `
  -Method Get `
  -Uri "$base/api/session" `
  -WebSession $customer

$currentSession | ConvertTo-Json -Depth 5

$currentSession.data.profile | Format-List


STEP 3 - BRANCH READ
====================

$branches = (
  Invoke-RestMethod `
    -Method Get `
    -Uri "$base/api/branches" `
    -WebSession $customer
).data

$branches |
  Select-Object branchNo, name, operatingStatus |
  Format-Table

Expected:

Branch 1 = active
Branch 2 = resting
Branch 3 = active
Branch 4 = active


STEP 4 - MEAL READ
==================

$meals = (
  Invoke-RestMethod `
    -Method Get `
    -Uri "$base/api/meals" `
    -WebSession $customer
).data

$mealId = $meals[0]._id

$meals |
  Select-Object _id, name, category, price |
  Format-Table

$mealId


STEP 5 - BOOKING CREATE
=======================

$bookingDate = (Get-Date).Date.AddDays(7)

while ($bookingDate.DayOfWeek -eq "Monday") {
  $bookingDate = $bookingDate.AddDays(1)
}

$bookingBody = @{
  branchNo = 1
  bookingDate = $bookingDate.ToString("yyyy-MM-dd")
  slotStart = "19:00"
  slotEnd = "21:00"
  partySize = 2
  notes = "Manual speed test"
}

$booking = Invoke-RestMethod `
  -Method Post `
  -Uri "$base/api/bookings" `
  -WebSession $customer `
  -ContentType "application/json" `
  -Body ($bookingBody | ConvertTo-Json -Compress)

$bookingId = $booking.data._id

$booking.data | Format-List

Expected:

status = pending
branchNo = 1
partySize = 2


STEP 6 - BOOKING READ
=====================

$bookingRead = Invoke-RestMethod `
  -Method Get `
  -Uri "$base/api/bookings/$bookingId" `
  -WebSession $customer

$bookingRead.data | Format-List


STEP 7 - BOOKING UPDATE
=======================

$bookingUpdateBody = @{
  branchNo = 1
  bookingDate = $bookingDate.ToString("yyyy-MM-dd")
  slotStart = "19:00"
  slotEnd = "21:00"
  partySize = 3
  notes = "Manual speed test updated"
}

$bookingUpdate = Invoke-RestMethod `
  -Method Patch `
  -Uri "$base/api/bookings/$bookingId" `
  -WebSession $customer `
  -ContentType "application/json" `
  -Body ($bookingUpdateBody | ConvertTo-Json -Compress)

$bookingUpdate.data | Format-List

Expected:

partySize = 3
notes = Manual speed test updated


STEP 8 - ORDER CREATE
=====================

$orderBody = @{
  branchNo = 1
  items = @(
    @{
      mealId = $mealId
      quantity = 1
    }
  )
}

$order = Invoke-RestMethod `
  -Method Post `
  -Uri "$base/api/orders" `
  -WebSession $customer `
  -ContentType "application/json" `
  -Body ($orderBody | ConvertTo-Json -Depth 5 -Compress)

$orderId = $order.data._id

$order.data | Format-List

Expected:

status = placed
items contains the selected meal
totalAmount is calculated by the server

STEP 13 - MEAL CREATE BY ADMIN
==============================

$temporaryMeal = Invoke-RestMethod `
  -Method Post `
  -Uri "$base/api/meals" `
  -WebSession $admin `
  -ContentType "application/json" `
  -Body (@{
    name = "Manual Speed Meal"
    category = "Test"
    description = "Temporary API test"
    price = 1.50
    isAvailable = $true
  } | ConvertTo-Json -Compress)

$temporaryMealId = $temporaryMeal.data._id

$temporaryMeal.data | Format-List


STEP 14 - MEAL UPDATE BY ADMIN
==============================

$mealUpdate = Invoke-RestMethod `
  -Method Patch `
  -Uri "$base/api/meals/$temporaryMealId" `
  -WebSession $admin `
  -ContentType "application/json" `
  -Body (@{
    price = 2.25
    isAvailable = $false
  } | ConvertTo-Json -Compress)

$mealUpdate.data | Format-List

Expected:

price = 2.25
isAvailable = false


STEP 15 - MEAL DELETE BY ADMIN
==============================

$mealDelete = Invoke-WebRequest `
  -Method Delete `
  -Uri "$base/api/meals/$temporaryMealId" `
  -WebSession $admin `
  -UseBasicParsing

$mealDelete.StatusCode

Expected:

204


STEP 16 - SESSION DELETE
========================

$logout = Invoke-WebRequest `
  -Method Delete `
  -Uri "$base/api/session" `
  -WebSession $customer `
  -UseBasicParsing

$logout.StatusCode

Expected:

204


STEP 17 - RESET THE DATABASE
============================

Stop the server with Ctrl+C in Terminal 1.

In Terminal 1:

npm run reset

This removes the test booking, test order, and any test meal records.
